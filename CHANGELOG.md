# Изменения

## 1.1.0 — 2026-10-23

- Короткое приветствие и команда «Справка» со списком команд.
- Команда получения фонового результата — «Чек» вместо «Продолжай».
- Удалена автоматическая атрибуция и кнопки источников из обычных ответов, повторов и выдачи готового результата.
- Источники сохранены для явного запроса, в том числе «Откуда информация».
- При наличии publisher источники подписаны именем издания.
- Часовой пояс по умолчанию UTC; личный часовой пояс задаётся через TIMEZONE.
- Отдельная обезличенная поставка для GitHub с пустыми ключами и ID.
- Регрессионные тесты для команд и хранения источников.
