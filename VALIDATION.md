# Проверка версии 1.1.0

2026-10-23: локально на Node.js 24.22.1 выполнены 22 теста и HTTP smoke без реальных внешних API. Целевой runtime проекта — Node.js 22; для него добавлен GitHub Actions workflow. Workflow ещё не запускался в GitHub.

Проверены авторизация вебхука, изоляция пользователей, история, дедупликация, лимиты, фоновая обработка, отмена запроса, отказ при ошибке поиска и некорректных источниках. Новые сценарии проверяют справку без вызова сервисов, короткое приветствие, «Чек», источники по явному запросу, их отсутствие в обычных ответах и очистку после сброса.

Модель в тестах заменена имитацией: тесты не доказывают фактическую точность новостей и безусловное соблюдение инструкций реальной моделью. На новом развёртывании необходимы проверки из README. Реальный production в рамках подготовки архива не обновлялся.

Поставка сформирована из выбранных исходных папок и документов, без .env, node_modules, снимков экрана, Git-истории и личной конфигурации. Проверка содержимого по известным личным ID, адресам и характерным форматам ключей не нашла совпадений. Это не универсальная гарантия обнаружения любого секрета: перед добавлением собственных файлов проверяйте их отдельно.
